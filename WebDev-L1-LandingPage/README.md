# NovaSpace Landing Page | OIBSIP Web Development Level 1 - Task 1

A polished, responsive landing page for a fictional productivity workspace brand called **NovaSpace**. This project was created for the Oasis Infobyte Web Development & Designing internship.

## Tech stack
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- CSS-only responsive mobile navigation

## Features
- Sticky navigation with Features, About, Reviews and Get Started links
- Hero section with headline, description and call-to-action
- Three feature cards, About section, testimonial and footer
- Consistent colour palette and typography
- Responsive desktop, tablet and mobile layouts
- CSS-only mobile navigation menu

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser. No build tools, JavaScript, or dependencies are required.

`OIBSIP/WebDev-L1-LandingPage/`
