# Personal Portfolio | OIBSIP Web Development Level 1 - Task 2

A responsive personal portfolio website for **Pankaj Kumar**, a B.Tech Computer Science and Engineering student at Cambridge Institute of Technology, Ranchi.

## Tech stack
- HTML5
- CSS3 (Flexbox, Grid, responsive media queries)
- Vanilla JavaScript for the mobile navigation menu

## Sections and features
- Hero section with name, role and visual avatar/monogram placeholder
- About Me section with education and interests
- Skills grid: HTML, CSS, JavaScript, Python, C and tools
- Two project cards: Amazon Clone UI and Calculator
- Contact section with email, LinkedIn and GitHub links
- Smooth scrolling and responsive mobile navigation
- Consistent dark theme with lime accent colour

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Before publishing
1. Replace `your.email@example.com` with your real email address.
2. Replace the generic GitHub and LinkedIn profile URLs with your own profile links.
3. Add a professional photo if you want; the current profile visual is a designed monogram placeholder.
4. Update project links to the exact repositories for your projects.
